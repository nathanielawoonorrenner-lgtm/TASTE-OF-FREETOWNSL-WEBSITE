# Taste of FreetownSL

**Calm · African · Multi-page restaurant website**

Web Design Assignment 2, by Nathaniel Ernest Awwonor Renner

Taste of FreetownSL is a website for a restaurant serving authentic Sierra Leonean food in Freetown. The design is calm and welcoming, with soft earthy colours and gentle African-inspired touches, so visitors can browse the menu, learn the story behind the food, and book a table.

---

## Pages

| Page | File | Purpose |
|---|---|---|
| Home | `index.html` | Introduction, highlights, and links to the rest of the site |
| Our Story | `about.html` | The idea and values behind the restaurant |
| Menu | `menu.html` | Sierra Leonean dishes, snacks, and drinks |
| Booking | `booking.html` | Table reservation form |
| Contact | `contact.html` | Location, contact details, and a message form |
| Styles | `style.css` | Shared styling for every page |

## Design approach

- **Calm look:** soft cream backgrounds, muted sage green and clay accents, generous spacing, and a subtle paper-like texture.
- **African inspiration:** warm earth tones, a gentle woven-pattern divider, and arch-shaped imagery, used sparingly so the content stays easy to read.
- **Typography:** Playfair Display for headings and DM Sans for body text, loaded from Google Fonts.
- **Consistency:** one shared stylesheet, with the same header, navigation, and footer on every page.
- **Usability:** a clear "Book a Table" button in the navigation, and simple menu and booking pages.

## Built with

- HTML5
- CSS3
- Google Fonts
- Visual Studio Code with Live Server for testing

## How to run

1. Download or clone this repository.
2. Keep all files in the same folder.
3. Open `index.html` in a web browser, or right-click it in VS Code and choose **Open with Live Server**.

An internet connection is needed to load the fonts and the images.
